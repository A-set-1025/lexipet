# LexiPet — Product Requirements Document

**产品名称：** LexiPet  
**产品标语：** Learn English. Grow Together.  
**文档版本：** v0.1  
**产品形态：** Web Application  
**产品阶段：** MVP Planning  
**目标平台：** Desktop Web，后续适配移动端

---

## 1. 产品概述（Product Overview）

LexiPet 是一个结合英语学习、智能复习和虚拟宠物养成机制的英语学习平台。

用户可以通过单词学习、常用句学习、自定义词库和学习笔记积累英语知识。系统根据用户的学习记录安排复习，并将学习成果转化为宠物经验、零食和成长进度。

产品希望解决传统英语学习过程中容易遗忘、缺乏系统规划和难以长期坚持的问题。

### 核心价值

1. 提供系统化的英语单词和句子学习体验。
2. 通过学习记录和复习安排帮助用户巩固知识。
3. 通过虚拟宠物和奖励机制提高学习动力。
4. 支持个性化词库、学习笔记和学习目标。
5. 为未来 AI 辅助学习和个性化推荐预留扩展能力。

---

## 2. 目标用户（Target Audience）

### 2.1 用户群体

面向所有希望提升英语能力的通用英语学习者。

覆盖 CEFR 英语水平：

- A1：初级入门
- A2：基础
- B1：中级
- B2：中高级
- C1：高级
- C2：精通

### 2.2 用户需求

- 希望扩大英语词汇量。
- 希望掌握常用英语表达和句型。
- 希望建立长期学习习惯。
- 希望及时复习已经学过的内容。
- 希望根据自己的水平和兴趣选择学习内容。
- 希望学习过程更有趣，而不是单纯重复记忆。

### 2.3 主要痛点

| 痛点 | 产品解决方案 |
|---|---|
| 学过的单词容易遗忘 | 学习记录与复习计划 |
| 不知道每天学什么 | 每日学习任务 |
| 只会背单词，不会使用 | 句子与语境学习 |
| 学习容易中断 | 宠物成长和奖励 |
| 学习内容不符合个人需求 | 自定义词库和学习设置 |

## 3. 产品目标（Product Goals）

### 3.1 核心目标

帮助用户形成持续、可追踪、有反馈的英语学习习惯。

### 3.2 产品指标

后续可以通过以下指标评估产品效果：

- 每日活跃学习用户数（DAU）
- 用户每周学习天数
- 单词和句子的完成数量
- 复习完成率
- 单词复习正确率
- 用户连续学习天数
- 用户留存率

初期先实现数据采集和统计，不预设未经验证的目标数值。

## 4. 核心功能（Core Features）

### 4.1 用户系统

- 用户注册
- 用户登录和退出
- 用户个人资料
- 英语水平设置（A1-C2）
- 每日学习目标设置
- 学习偏好设置

### 4.2 单词学习（Vocabulary Learning）

- 查看预设词库
- 创建个人词库
- 手动添加单词
- 查看单词释义、音标和词性
- 查看例句和翻译
- 单词发音
- 单词卡片学习
- 选择题和拼写测试
- 收藏单词
- 错词本
- 记录单词熟悉程度
- 根据学习记录安排复习

### 4.3 句子学习（Sentence Learning）

- 查看预设句子内容
- 查看英文原句和中文翻译
- 查看重点词汇
- 查看语法说明
- 查看使用场景
- 句子收藏
- 句子学习进度
- 句子练习和测试

### 4.4 词库管理（Vocabulary Management）

- 创建词库
- 编辑词库
- 删除词库
- 添加和移除词汇
- 设置词库名称、描述和英语水平
- 区分公共词库与私人词库

未来扩展：

- AI 根据主题生成词库
- AI 根据难度生成词库
- 词库导入和导出
- 公开分享词库

### 4.5 学习笔记（Study Notes）

- 创建笔记
- 编辑笔记
- 删除笔记
- 搜索笔记
- 标签管理
- 关联单词和句子

### 4.6 虚拟宠物（Virtual Pet）

宠物系统由两个部分组成：

**成长与奖励**

- 用户完成学习任务获得经验值。
- 用户获得零食奖励。
- 宠物通过经验值提升等级。
- 用户可以使用零食进行互动。
- 宠物随着等级变化解锁外观或装饰。

**陪伴与互动**

- 宠物具有基础心情状态。
- 宠物具有基础饥饿状态。
- 用户可以喂养宠物。
- 用户可以与宠物互动。
- 宠物状态可以提供陪伴反馈。

设计原则：宠物系统应鼓励学习，而不是惩罚用户。用户暂时停止学习时，不应因为宠物状态变化而承受过强的负面反馈。

### 4.7 学习统计（Learning Statistics）

- 今日学习数量
- 累计学习单词数
- 累计学习句子数
- 复习完成情况
- 学习连续天数
- 学习历史记录
- 宠物成长记录

## 5. MVP 功能范围（Minimum Viable Product）

第一版的目标是开发一个真实可用的英语学习产品，而不是静态页面 Demo。

### P0：第一版必须实现

1. 用户注册、登录和退出。
2. 用户英语水平和每日学习目标设置。
3. 预设词库浏览。
4. 用户自定义词库。
5. 手动添加单词。
6. 单词卡片学习。
7. 基础单词测试。
8. 单词收藏和错词本。
9. 基础复习安排。
10. 预设句子学习。
11. 学习笔记的创建、编辑和删除。
12. 基础宠物系统。
13. 学习经验和零食奖励。
14. 基础学习统计。

### P1：后续版本

- AI 自动生成词库。
- AI 生成句子和例句。
- 个性化学习计划。
- 智能推荐学习内容。
- 更完善的复习算法。
- 宠物外观和装饰系统。
- 更丰富的宠物互动。
- 词库分享和导入导出。

### 暂不考虑

- 社交社区和好友系统。
- 实时多人学习。
- 复杂的宠物经济系统。
- AI 实时语音对话。
- 原生 iOS 和 Android 应用。

## 6. 核心业务规则（Business Rules）

### 6.1 学习进度

单词和句子的学习进度属于用户个人数据。

不同用户学习同一个公共单词时，必须拥有独立的学习记录。

### 6.2 词库归属

词库分为：

- 公共词库：平台提供，所有用户可以浏览和学习。
- 私人词库：由用户创建，默认仅创建者可访问。

私人词库必须经过后端权限验证，不能只依靠前端隐藏。

### 6.3 学习奖励

- 只有有效完成的学习活动才能获得奖励。
- 同一次学习活动不能重复发放奖励。
- 奖励的获得和消费必须有记录。
- 宠物经验和零食的变化必须能够追溯。

### 6.4 复习规则

初期采用简单的间隔复习策略。

系统根据用户的学习结果安排下一次复习时间。

未来再根据实际学习数据优化复习算法。

### 6.5 英语水平

所有学习内容应支持 CEFR 等级标记。

第一版的数据结构应允许 A1-C2 内容共存，但不要求上线时已经拥有完整的六个等级内容库。

## 7. 核心用户流程（User Flow）

1. 用户注册并登录。
2. 用户选择自己的英语水平。
3. 用户设置每日学习目标。
4. 用户选择预设词库或创建个人词库。
5. 用户进入每日学习页面。
6. 用户学习单词和句子。
7. 用户完成练习和测试。
8. 系统保存学习记录并安排复习。
9. 用户获得宠物经验和奖励。
10. 用户与宠物互动。
11. 用户查看学习统计和进度。

## 8. 非功能需求（Non-functional Requirements）

### 性能

- 页面应具有合理的加载速度。
- API 应避免不必要的数据库查询。
- 学习记录应及时保存。

### 安全

- 密码必须经过安全哈希处理。
- 用户只能访问自己有权限的数据。
- 身份验证必须由后端执行。
- AI API Key 不得暴露在前端。
- 对关键接口实施必要的输入验证和限流。

### 可维护性

- 前端与后端分离。
- 采用清晰的模块结构。
- 数据库使用迁移管理。
- 核心业务逻辑应具备自动化测试。
- 使用 Git 管理版本。

### 可扩展性

- 支持后续接入 AI 服务。
- 支持更多词库和句子内容。
- 支持后续扩展移动端或微信小程序。
- 宠物奖励机制应与学习业务逻辑适当解耦。

## 11. MVP 验收标准（Acceptance Criteria）

第一版至少满足：

- 用户可以注册、登录和退出。
- 用户可以创建自己的词库并添加单词。
- 用户可以学习单词和句子。
- 用户可以完成测试并查看结果。
- 系统可以保存个人学习进度。
- 用户可以查看收藏和错词。
- 系统能够安排基础复习。
- 用户可以创建和管理学习笔记。
- 学习完成后能够获得对应奖励。
- 宠物能够升级并进行基础互动。
- 用户可以查看自己的学习统计。
- 不同用户的数据相互隔离。
- 核心功能通过必要的自动化测试。

## 12. 风险与待确认事项（Risks & Open Questions）

1. A1-C2 内容覆盖范围和首批内容来源。
2. 单词释义、例句和音频的版权与数据来源。
3. 复习算法的具体参数。
4. 宠物饥饿和心情状态如何随时间变化。
5. 学习奖励如何防止重复发放。
6. AI 生成内容的质量验证方式。
7. 用户隐私、数据导出和账户删除机制。

这些问题将在后续系统设计阶段进一步确定。
